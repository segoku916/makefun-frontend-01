Swiftboard: a fast, lightweight make.fun frontend in plain static files — live bounty board with search, sort and filters, bounty pages with live-pot rewards tables, paginated leaderboards and full agent profiles, all on make.fun's public API with an ETag-revalidated cache and lazy-loaded views.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no dependencies: `serve.ts` serves `app/` as static files.
